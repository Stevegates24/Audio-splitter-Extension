🔀

True simultaneous routing

Audio is duplicated at the Web Audio graph level and sent to each output with a separate AudioContext — not mixed back together.

🎚

Per-device EQ

3-band parametric EQ on every output independently. Boost bass for the TV, cut highs for the headphones.

🌀

Natural 8D audio

Four overlapping LFOs at prime-ratio frequencies plus a slow drift wave — the orbit never repeats the same pattern twice.

⚡

Zero latency updates

EQ and volume changes push live to the audio graph via setTargetAtTime — no dropout, no re-routing.

/ install

Up in 60 seconds.

No Chrome Web Store, no waiting for review. Load it directly from the source.

1

Download the extension

Clone the repo or download the ZIP and unzip it to a permanent folder on your Chromebook.

git clone https://github.com/Stevegates24/Steves-Audio-Mixer
2

Enable Developer mode

Open Chrome and navigate to the extensions page. Toggle Developer mode in the top-right corner.

chrome://extensions
3

Load the folder

Click "Load unpacked" and select the extension folder. The icon appears in your toolbar immediately.

4

Go to a media tab and apply

Open YouTube or Spotify Web. Click the extension, select your outputs, toggle On, and hit Apply.
